# 經典密碼概念

經典密碼的重點不在於「看起來很複雜」，而在於它如何改變文字的排列或字母對應。凱撒、Atbash、維吉尼亞、仿射與 Playfair 都屬於替換系統；欄柵、欄位換位與天書棒則屬於換位系統。

## 替換與換位

替換密碼保留文字的位置，但替換每個字母。換位密碼保留字母本身，改變它們出現的順序。兩者可以疊加，但單獨使用時都容易受到頻率分析或已知明文攻擊。

## 解碼與解密

在本工具中，解碼模式會反轉同一個可逆流程。Base32、Base64、Hex 與 URL 是編碼，不是密碼；它們的目的在於表示資料，不是隱藏資料。

## 安全提醒

這些方法適合課堂、相容性、謎題與歷史研究。需要保護真實機密時，請使用經過審核的現代加密協定與密鑰管理方式。
